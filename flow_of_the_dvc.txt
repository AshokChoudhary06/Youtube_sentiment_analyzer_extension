1. install cookiecutter 
	-pip install cookiecutter
2. add the template of the cookiecutter
	- cookiecutter -c v1 http://github.com/datadriven/coookiecutter-data-science
3. delete files in src folder

4. create venv
	- python -m venv my_env_name
	- my_env_name/Scripts/activate
5. Create a github repo 

6. git init in the terminal of vscode

7. add git remote 
	- git remote add origin <url>

8. git add 

9. git commit 

10. git push origin or <url> master

11. install dvc
	- pip install dvc

12. dvc init 

13. dvc add remote for temporary data storage 
  	-dvc remote add -d myremote D:\Temp

14. to add the dvc.yaml 
dvc stage add 
-n data_ingestion #name of the dvc_stage
-d src/data/data_ingestion.py #Dependency of the files 
-p data_ingestion.test_size # Parameter in the pipeline stage 
-o data/raw  # output of the dvc stage that is data folder 
python src/data/data_ingestion.py

same way we add another levels of stages to the dvc
